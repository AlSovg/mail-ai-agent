# 04. Scope MVP

## Входит
- Подключение Почты Mail с явного согласия. Домены ящиков: mail.ru, bk.ru, inbox.ru, list.ru, internet.ru, xmail.ru.
- Сводка важных писем **по запросу пользователя** (pull). Push-дайджест технически возможен (ответ MAX 2026-10-01: бот пишет сам, если диалог начат и бот не заблокирован), но MAX прямо не ответил, считается ли он «сервисным» по п. 1.5 → в MVP только по явной подписке, после первого сообщения пользователя; риск принимаем осознанно либо уточняем.
- Поиск писем по естественному языку.
- Краткий пересказ цепочки.
- Письма, требующие ответа или действия.
- Черновики ответов: текст показывается в чате, в «Черновики» Mail попадает только после нажатия кнопки; для подозрительных писем черновик не создаётся (`02-security.md` §5.1).
- Действия с письмами — только после явного подтверждения.

## Не входит
- Ящики VK Почты (домен vk.com): IMAP/POP/SMTP там недоступны (ответ поддержки Mail, 2026-09-30). При подключении такого адреса онбординг сразу сообщает, что он не поддерживается.
- Автоматическая отправка писем.
- Удаление сообщений.
- Передача содержимого почты третьим лицам без отдельного подтверждения.

## Критерии успеха
Решение «продолжать / менять / остановить» после пилота. Пороги заданы заранее. Пометка **[из 05]** — взято из `05-discovery.md`, остальное — предложение (2026-10-01), можно оспорить. Выборка малая (5–10 пользователей), результаты показывают направление, а не статистику.

**Безопасность (обязательные, без исключений)**
- Ни один текст атаки из набора `inj_*` не проходит через шлюз и фильтр в черновик или сводку (`02-security.md` §5.1 п. 6).
- В коде нет операций SEND и DELETE; ни одного письма не отправлено и не удалено агентом за пилот (проверка по `audit_log`).
- Ни одно изменяющее действие без подтверждения; replay токена и поддельный webhook отклоняются (тесты этапа 4).
- В логах и БД нет тел писем.

**Качество ответов** (набор писем + пилот)
- ≥ 80% ответов «полезно», критичных пропусков (важное письмо не попало в сводку) единицы **[из 05]**.
- «Требует ответа» / решения: ≥ 0.9 на обезличенном наборе (на синтетике 30 писем Qwen3-14B показал 0.93–0.97, `07-llm-scenario-test.md`); на реальных обезличенных письмах не проверено.
- Выдумок фактов (письмо, которого нет; чужие реквизиты) в проверочной выборке: 0.

**Использование и доверие (пилот)**
- ≥ 50% пилотных пользователей возвращаются на 2-й неделе **[из 05]**.
- Доля прошедших онбординг до подключённого ящика: ≥ 60% начавших (потери на включении IMAP — известный барьер).
- Отключили доступ (`/disconnect` или отзыв) по причине недоверия: не более 1 из 5 пользователей.
- Оценка полезности ≥ 4 из 5 в среднем.

**Эксплуатация**
- Webhook отвечает 200 быстрее 30 с в 99% событий; дублей обработки 0.
- Затраты на LLM на активного пользователя в месяц укладываются в расчёт `06-economics.xlsx` (порог уточнить после выбора провайдера).

**Решение по результату:** «продолжать» — выполнены все обязательные по безопасности и использование + качество; «менять» — безопасность выполнена, не хватает качества или удержания; «остановить» — нарушен хотя бы один обязательный пункт по безопасности либо готовность подключить ящик ниже 20% **[из 05]**.
